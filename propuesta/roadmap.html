Roadmap de desarrollo

Cada MVP entrega funcionalidad end-to-end verificable. Fases secuenciales.

MVP 1 · Base + Tracking

En ejecución · 100%

Plataforma base operativa. Envío de coordenadas desde móvil al backend y visualización en panel.

✓ Backend FastAPI + arquitectura modular
✓ PostgreSQL + Alembic migraciones
✓ API REST + OpenAPI docs
✓ Auth JWT + refresh rotation
✓ CRUD usuarios + roles
✓ Panel admin básico
✓ Tabla coordenadas + PostGIS
✓ Docker + docker-compose
✓ Seguridad básica (bcrypt, CORS, rate limit)
✓ Logging estructurado structlog

MVP 2 · Tracking en tiempo real

Pendiente ~1 mes

Visualización de ubicación sobre mapa con actualización en vivo vía WebSockets.

Servidor Socket.io integrado con FastAPI
Endpoint streaming de coordenadas por courier
Vista de mapa con markers live
Indicador online/offline con heartbeat
Optimización: batching de coords según movimiento
Reconexión automática + fallback long-polling

MVP 3 · Gestión de repartidores + notificaciones

Pendiente ~1 mes

Módulo completo de onboarding, disponibilidad y operación del repartidor.

Onboarding con upload de documentos (S3/MinIO)
Panel de repartidor (perfil, toggle, historial)
Aprobación manual desde backoffice
Integración FCM para push notifications
Email transaccional (SMTP)
Cola interna con retry exponencial

MVP 4 · Catálogo + Pedidos + Pagos

Pendiente ~1 mes

Ciclo completo: catálogo del comercio → pedido → pago → asignación manual.

CRUD completo de productos y variantes
Carga masiva CSV con validación async
Categorías jerárquicas + búsqueda full-text
Máquina de estados de pedido
Integración pasarela local (adapter pattern)
Webhooks de confirmación asíncronos
Idempotencia en pagos
Carrito y checkout
Asignación manual desde backoffice
Job limpieza pedidos stale

MVP 5 · Asignación inteligente + Comisiones + Ratings

Pendiente ~1 mes

Asignación automática al repartidor más cercano, motor de comisiones parametrizable y sistema de ratings.

Query PostGIS ST_DWithin + scoring
Timeout y reasignación automática
Fallback a asignación manual tras N intentos
Motor paramétrico de comisiones
Job diario de expiración de contratos
Log inmutable de cambios críticos
Sistema de ratings 1-5 con fórmula Bayes
Cálculo nocturno de ratings promedio

MVP 6 · Producción y hardening

Pendiente ~1 mes

Preparación del sistema para despliegue productivo con observabilidad completa.

Dashboard métricas técnicas (Prometheus + Grafana)
Optimización de queries + índices compuestos
Seguridad avanzada + auditoría completa
CI/CD con pipelines (lint + test + build + deploy)
Backup automático de BD
Pruebas de carga (k6 o Locust)
Documentación técnica completa
Plan de deploy + runbook operativo

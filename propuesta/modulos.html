Módulos funcionales

Desglose por dominio. Cada módulo es un paquete Python autocontenido.

🔐 Auth

MVP 1
  • • Registro con email + teléfono
  • • Login con JWT (access 15min, refresh 7 días)
  • • Recuperación de contraseña por email
  • • Roles: client, merchant, courier, admin
  • • Refresh token rotation (revocación)
  • • Futuro: OTP, 2FA, social login

👥 Users

MVP 2
  • • CRUD de usuarios
  • • Perfiles extendidos por tipo
  • • Gestión de direcciones guardadas (cliente)
  • • Suspensión / baneo por admin
  • • Soft delete con marca temporal

🏪 Merchants

MVP 3
  • • Onboarding multi-paso
  • • Firma digital contrato adhesión
  • • Tipos: tienda_barrio, puesto_mercado, supermercado, mayorista
  • • Modalidades: unitaria, mayorista, mixta
  • • Configuración de horarios (JSONB)
  • • Zona de cobertura (polígono GeoJSON)
  • • Aprobación manual por admin

🛵 Couriers

MVP 3
  • • Onboarding + carga documentos (DNI, licencia, seguro)
  • • Verificación manual por admin
  • • Tipo vehículo: moto, bici, auto, a pie
  • • Toggle disponibilidad (online/offline/en_pedido)
  • • Última ubicación conocida
  • • Rating y estadísticas operativas

📦 Catalog

MVP 4
  • • Categorías jerárquicas (padre/hijo)
  • • Productos con nombre, descripción, precio, stock
  • • Variantes (talla, color, tamaño) con precio adicional
  • • Carga individual y masiva (CSV)
  • • Imágenes (S3/MinIO)
  • • Estados: activo, agotado, descontinuado
  • • price_tiers JSONB para precios escalonados (mayorista futuro)

🛒 Orders

MVP 4
  • • Máquina de estados: creado → confirmado → preparando → listo → asignado → en_camino → entregado
  • • Items con referencia a productos y variantes
  • • Cálculo de totales (subtotal, envío, comisión, propina)
  • • Cancelación con motivo
  • • Tiempos estimados de entrega
  • • Notas al comercio y al repartidor
  • • Timeout de confirmación (configurable)

📍 Geo

MVP 2
  • • Tabla courier_locations con PostGIS Point
  • • Inserción optimizada (batch)
  • • Índices GIST para queries de proximidad
  • • Zonas de cobertura (MultiPolygon)
  • • Query: "repartidores en radio N km"
  • • Streaming por WebSocket en tiempo real
  • • Retención: 90 días con purgado automático

💰 Commissions

MVP 5
  • • Motor paramétrico por entidad
  • • Tipos: porcentaje, tarifa_fija, suscripción, ninguno
  • • Vigencia (inicio/fin)
  • • Job diario: detecta vencidos → notifica → espera aceptación
  • • Log inmutable de cambios (append-only)
  • • Versionado de términos de contrato
  • • Editable desde backoffice sin deploy

💳 Payments

MVP 4
  • • Adapter pattern para múltiples gateways
  • • Métodos: tarjeta, efectivo, wallet interna
  • • Webhooks para confirmaciones asíncronas
  • • Idempotencia (clave por pedido)
  • • Conciliación diaria
  • • Reembolsos parciales/totales

🔔 Notifications

MVP 3
  • • Push móvil (FCM)
  • • Email transaccional (SMTP)
  • • WebSockets para estado en vivo
  • • Templates versionados
  • • Preferencias por usuario (opt-out)
  • • Cola interna para retries

⭐ Ratings

MVP 5
  • • Calificación 1-5 de comercio y repartidor
  • • Comentarios con moderación
  • • Cálculo de rating promedio con fórmula de Bayes
  • • Solo permitido a clientes que completaron pedido
  • • Ventana de 7 días post-entrega

🎯 Assignment

MVP 5
  • • Selección de repartidor disponible más cercano
  • • Filtros: radio máximo, tipo vehículo, rating mínimo
  • • Timeout de aceptación (30s)
  • • Reasignación automática si rechaza
  • • Fallback a asignación manual tras N intentos
  • • Futuro: scoring ML con historial

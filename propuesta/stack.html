Stack tecnológico

Justificación técnica de cada elección. Prioridad: open source, gratuita, mantenida activamente.

Capa Tecnología Justificación Estado
App móvil React Native Build único para iOS y Android. Un codebase, dos plataformas. Librería react-native-maps para mapas, react-native-background-geolocation para tracking. Pendiente
Panel web (Comercio + Backoffice) Angular 22 Un solo framework para ambos SPA. Standalone components por defecto, estado reactivo con signals, change detection zoneless, control flow @if/@for, typed forms, SSR con hydration, y CLI + Vitest + i18n integrados. Open source, mantenido por Google con LTS garantizada. Pendiente
Backend Python 3.12 + FastAPI Async nativo con asyncio, type hints completos, validación automática con Pydantic v2, documentación OpenAPI gratis. Comunidad madura. En uso
ORM SQLAlchemy 2.0 (async) Patrón Unit of Work, sessions async con asyncpg, integración directa con PostGIS vía GeoAlchemy2. Estándar de la industria. En uso
Migraciones Alembic Migraciones versionadas y reproducibles. Autogeneración a partir de cambios en modelos SQLAlchemy. En uso
BD principal PostgreSQL 16 + PostGIS ACID, JSONB para datos semi-estructurados, índices GIN/GIST, full-text search integrado, funciones geoespaciales nativas. En uso
Tiempo real Socket.io (Node adapter) WebSockets con fallback automático (long-polling). Cliente oficial en Python via python-socketio. Redis adapter para multi-instancia. Pendiente
Caché Redis 7 Caché de queries pesadas, sesiones de WebSocket, rate limiting distribuido, broker para Socket.io adapter. Se activa cuando la carga lo justifique. Futuro
Mapas OpenStreetMap + Leaflet Tile server open source (OpenMapTiles o similar). Leaflet envuelto en componentes Angular para los paneles web, react-native-maps con provider OSM para móvil. Pendiente
Búsqueda avanzada PostgreSQL FTS → Meilisearch MVP: full-text search con tsvector + GIN index. Futuro: Meilisearch (open source, compatible API Algolia) si la escala lo exige. Futuro
Push notifications Firebase Cloud Messaging Única excepción no-open-source. Requerido por Apple/Google para push en móvil. SDK oficial firebase-admin en Python. Pendiente
Pagos Pasarela local (adapter) Patrón Adapter para abstraer proveedor. Permite cambiar de gateway sin tocar lógica de dominio. Se define al iniciar operaciones. Pendiente
Validación / Schemas Pydantic v2 Validación con type hints, serialización ultra-rápida (Rust-core), integración nativa con FastAPI. En uso
Logging structlog Logs estructurados en JSON. Contexto automático por request (request_id, user_id). Compatible con cualquier agregador. En uso
Testing pytest + httpx + factory_boy pytest para test runner, httpx para testing async de APIs, factory_boy para fixtures de datos. Pendiente
Testing API Bruno Cliente API open source, ligero y rápido. Colecciones en formato de archivos plano (versionable en Git). Soporte para variables de entorno, scripts pre-request, assertions. Alternativa open source a Postman sin telemetría ni cloud obligatorio. Pendiente
CI/CD GitHub Actions / Gitea Pipelines automáticos de lint + test + build. Gitea como alternativa self-hosted gratuita post-inversión. Futuro
Contenedores Docker + Docker Compose Entorno reproducible. docker-compose up levanta backend + DB + migraciones. Base para Kubernetes futuro. En uso
Versionado Git local Hasta definir proveedor cloud (GitHub/GitLab/Gitea self-hosted). En uso
Infraestructura A definir Post inversión. Candidatos: Hetzner (coste bajo), AWS (ecosistema), DigitalOcean (simplicidad). Futuro

Observabilidad

  • • Logs JSON vía structlog
  • • Métricas con prometheus-client
  • • Error tracking: Sentry (self-hosted)
  • • Tracing: OpenTelemetry (preparado)

Scheduler

  • • APScheduler (run_once jobs + cron periódicos)
  • • run_once: expiración contratos (fecha elegida por cliente), ofertas con vencimiento
  • • Cron periódico: limpieza pedidos stale, limpieza temp files
  • • Trigger on-write: cálculo ratings (al recibir nueva reseña)
  • • Webhooks: confirmaciones de pago (event-driven, no cron)
  • • Futuro: Celery + Redis si crece

Storage de archivos

  • • MVP: filesystem local + endpoint estático
  • • Futuro: MinIO (S3-compatible open source)
  • • Uso: fotos documentos, evidencia entregas

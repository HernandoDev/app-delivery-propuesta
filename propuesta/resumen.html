Alcance técnico

Plataforma de logística multiproveedor compuesta por 4 interfaces (app cliente, app repartidor, panel comercio, backoffice admin) sobre un backend único construido como monolito modular en Python/FastAPI. El sistema gestiona el ciclo completo: onboarding de actores, catálogo, pedidos, tracking geoespacial y administración operativa.

Principios de arquitectura

  • •Monolito modular con DDD. Paquetes por dominio (auth, catálogo, pedidos, geo, notificaciones, comisiones). Evita la sobrecarga operativa de microservicios en etapa temprana y permite extraer un módulo cuando la carga lo justifique.
  • •Parametrización total. Valores de negocio (comisiones, tarifas, límites) residen en base de datos. Cero despliegues para cambios de reglas.
  • •Stack abierto por defecto. Solo se integran servicios externos cuando no existe alternativa técnicamente viable.
  • •Iterativo y verificable. Cada MVP entrega funcionalidad end-to-end desplegable y testeable.

Decisiones técnicas clave

  • •Multi-plataforma desde día 1. React Native con un único codebase para iOS y Android.
  • •Python por expresividad. FastAPI para APIs async tipadas con Pydantic, validación automática y documentación OpenAPI.
  • •PostGIS para geoespacial. Evita soluciones externas para queries de proximidad y polígonos.
  • •Desarrollo lean. Un solo desarrollador full-stack. Git local hasta levantar infraestructura cloud dedicada.

API REST

Endpoints principales agrupados por dominio. Todos los endpoints REST usan JSON y siguen OpenAPI 3.1.

🔐 Auth

POST/auth/registerRegistro nuevo usuario (cliente por defecto)Public
POST/auth/loginLogin email/password → access+refresh tokensPublic
POST/auth/refreshRenueva access token con refresh tokenAuth
POST/auth/logoutRevoca refresh tokenAuth
POST/auth/forgot-passwordEnvía email con token de resetPublic
POST/auth/reset-passwordAplica nueva contraseña con tokenPublic
GET/auth/meUsuario autenticado con perfilAuth
